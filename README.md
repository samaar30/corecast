# CORECAST
### One platform. Every kind of content.

Corecast is a modern video, livestreaming, social and music platform where everyone can watch, create, upload and share content.

The goal is to build a platform with the best parts of YouTube, YouTube Shorts, livestreaming platforms and music streaming services — while giving Corecast its own unique design and identity.

---

# 1. MAIN NAVIGATION

The main navigation must be visible at the top of the website.

It must include:

- **Search** – Search for videos, creators, channels, music, artists, posts and live streams.
- **Home** – The main homepage with recommended content, popular videos and updates.
- **Live** – A dedicated page for live streams.
- **Music** – A separate music streaming experience.
- **Shorts** – A page dedicated to short-form vertical videos.
- **Post** – A page for community posts and updates.

The navigation should be easy to use on both desktop and mobile.

At the top-right corner, there should be a user account area with:
- Profile picture or account icon.
- Sign in / Sign up when logged out.
- User profile and account menu when logged in.
- Notifications.
- Creator upload options.

---

# 2. USER ACCOUNTS AND LOGIN

Users should be able to create an account and log in using:

- Google sign-in.
- Gmail through Google sign-in.
- Phone number with verification.

Users should have:
- Username.
- Display name.
- Profile picture.
- Biography.
- Followers.
- Following.
- Uploaded videos.
- Shorts.
- Posts.
- Playlists.
- Music, if they have an artist profile.

One person should be able to use one account for normal viewing, video creation and music publishing.

Login must be implemented securely using a proper authentication provider. Passwords and verification codes must never be stored as plain text.

---

# 3. SEPARATE UPLOAD SYSTEMS

Corecast must have five separate upload options. Each option must have its own upload page and workflow.

## A. Upload Video

Users can upload normal, long-form videos.

Features:
- Video file upload.
- Video title.
- Description.
- Thumbnail upload.
- Category.
- Tags.
- Visibility settings: Public, Unlisted or Private.
- Comments on/off.
- Age and content settings where appropriate.
- Publish button.
- Save as draft.

Uploaded videos should appear on the creator's channel and in relevant discovery pages.

## B. Upload Shorts

Shorts should have their own upload experience.

Features:
- Vertical video upload.
- Support for short-form video formats.
- Title and description.
- Thumbnail selection.
- Visibility settings.
- Comments on/off.
- Publish button.

Shorts should appear in a vertical scrolling feed where users can watch one short video after another.

## C. Go Live

Live streaming must have its own dedicated page.

Features:
- Stream title.
- Stream description.
- Thumbnail.
- Category.
- Public or private stream settings.
- Start stream button.
- Live chat.
- Viewer count.
- End stream button.

Live streaming will require a proper streaming service and backend infrastructure. It should not be simulated as a real public livestream in the final product.

## D. Create Post

Users and creators should be able to publish community posts.

Features:
- Text posts.
- Image posts.
- Polls.
- Links.
- Comments.
- Likes.
- Sharing.
- Visibility settings.

Posts should appear on creator channels and in the Post section.

## E. Upload Music

Music must have its own separate upload system and its own experience inside Corecast.

There should be two upload modes:

### Simple Upload
For hobby musicians and beginners.

Required:
- Song title.
- Artist name.
- Audio file.

Optional:
- Cover art.
- Description.

### Advanced Release
For artists who want to provide more release information.

Fields:
- Song title.
- Primary artist.
- Featured artists.
- Songwriters.
- Composers.
- Producers.
- Album cover.
- Lyrics.
- Genre.
- Release date.
- Language.
- Explicit content setting.
- Record label.
- Copyright information.
- Optional ISRC.
- Release type: Single, EP or Album.
- Track number.
- Album association.
- Version: Original, Acoustic, Remix or other.

Publishing music should be free for hobby artists and independent musicians. Artists should not need a record label, professional studio or ISRC code to publish.

Free publishing should have reasonable storage and fair-use limits to keep the platform sustainable.

Users must only upload music they own or have permission to distribute.

It should have:
- Music search.
- Artist pages.
- Albums.
- Singles.
- EPs.
- Playlists.
- Music recommendations.
- Popular tracks.
- New releases.
- Recently played.
- Liked songs.
- Queue.
- Shuffle.
- Repeat.
- Music player.
- Lyrics.
- Artist credits.

The music player should continue playing while users browse other parts of Corecast.

Artist profiles should be available to everyone, including hobby musicians.

An artist profile should include:
- Artist name.
- Profile picture.
- Banner.
- Biography.
- Discography.
- Singles, EPs and albums.
- Followers.
- Listening statistics.
- Announcements.
- Optional verified badge.

# 10. DESIGN AND USER EXPERIENCE

Corecast should have a modern, premium and recognizable design.

Design goals:
- Dark theme by default.
- Clean layout.
- Smooth animations.
- Rounded cards.
- Clear typography.
- Modern icons.
- Responsive desktop and mobile layouts.
- Fast loading.
- Easy navigation.
- Consistent design across all sections.

The music section should have its own visual identity while still feeling like part of Corecast.

The platform should not look like a direct copy of YouTube or Spotify. It should have its own branding and interface.

---

# 11. CREATOR PROFILES

Every creator should have a public channel/profile.

The channel should include:
- Profile picture.
- Banner.
- Name.
- Username.
- Biography.
- Subscribe/follow button.
- Videos.
- Shorts.
- Live streams.
- Posts.
- Playlists.

Users should be able to customize their channel.

A normal user account, video creator channel and music artist profile should be separate concepts, but connected to the same account.

---

# 12. SAFETY AND MODERATION

Corecast must include:
- Report content.
- Block users.
- Mute users.
- Comment moderation.
- Privacy settings.
- Account security.
- Copyright reporting.
- Community guidelines.
- Moderation tools for administrators.

Personal information and account data must be protected.

---

# 13. TECHNOLOGY AND DEVELOPMENT

The project should be built using a scalable architecture.

Suggested technologies:

- Frontend: HTML, CSS and JavaScript, or React.
- Backend: Node.js or another suitable backend.
- Database: Supabase or PostgreSQL.
- Authentication: Secure Google and phone authentication.
- Video storage: Dedicated video storage and streaming provider.
- Audio storage: Dedicated media storage.
- Hosting: A suitable web hosting provider.

GitHub should be used for source code and project management, not as the main storage location for uploaded videos or music.

The application must be designed so that real users can use the platform from different devices.

# THE CORECAST VISION

Corecast should be a place where everyone can watch, create, share and discover.

A platform where a person making music in their bedroom can publish alongside established artists.

A platform where creators can upload videos, make Shorts, go live and communicate with their community.

**Corecast is more than a video platform. It is a complete creative and entertainment platform.**
